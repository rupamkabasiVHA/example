# Advanced Module Challenge

## Objective
Complete the following tasks without recreating infrastructure where possible.

## Tasks
1. Create reusable VPC module.
2. Pass variables into module.
3. Expose outputs.
4. Reuse module across environments.
5. Add module version pinning.

## Skills Tested
- modules
- outputs
- inputs
- reusability


## Recommended Workflow

```bash
terraform init
terraform fmt
terraform validate
terraform plan
```

## Important Notes
- Do not manually edit terraform.tfstate
- Prefer safe refactoring
- Ensure terraform plan is clean
- Use modules where possible

## Bonus Exercise
Time yourself and complete within 20 minutes.
